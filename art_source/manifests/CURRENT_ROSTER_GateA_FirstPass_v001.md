목적은 CH101 한 명을 깊게 확정하기 전에 CH101~CH105가 **한 화면에서 모두 다른 캐릭터로 읽히는지** 확인하는 것이다. 예전 플레이 화면은 고유 외형 복제 대상이 아니라 `즉각적인 서브컬처 상품성·얼굴 매력·색 분리·파티 화면 가독성`의 품질 축으로만 사용한다.

## 1. 공통 품질 목표

- 5명 모두 성인 여성으로 즉시 읽힌다.
- 작은 전투 화면에서도 얼굴/헤어/큰 색면/대표 장비 중 최소 2개가 캐릭터마다 남는다.
- 검정 테크웨어 + 포인트색만 바꾼 팔레트 스왑으로 수렴하지 않는다.
- 직업 코스튬보다 도시형 패션과 탐험·생존 기능을 결합한다.
- 각 캐릭터는 하나의 대표 동적 장비만 강하게 보이고, 나머지는 정적 Mesh/VFX로 단순화 가능해야 한다.
- 2D 매력은 높이되 3D 쿼터뷰에서 삭제/결합 가능한 장식 구조를 유지한다.
- 외부 작품의 고유 얼굴·의상·무기·포즈·UI를 직접 복제하지 않는다.

## 2. CH101 아마사와 린 — Signal Runner

핵심 패션: 스포티 레이싱 / 도시형 기동복.

- 큰 색면: 펄 화이트 + 딥 차콜 + 청록.
- 헤어: 펄 블랙 단발 + 청록 언더라이트 + 한쪽 긴 묶음.
- 대표 장비: 단일 와이어 세이버 + 하나의 큰 신호 리본.
- 실루엣: 낮은 전진 자세, 비대칭 크롭 재킷, 속도감.
- 금지: 고양이 귀, 후드 정찰병, 쌍단검, 닌자형 회귀.

## 3. CH102 키사라기 마오 — Salvage Architect

핵심 패션: 메이커 워크웨어 / 비대칭 구조 패션.

- 큰 색면: 울트라바이올렛 + 그래파이트 + 회백색, 산성 레몬 포인트.
- 헤어: 잿빛 라벤더 롱 보브 + 산성 레몬 언더라이트 + 한쪽 긴 앞머리.
- 대표 장비: 접이식 자기 활 + 하나의 큰 구조 프레임.
- 실루엣: 한쪽 큰 소매, 다른 쪽은 가볍게 노출된 작업 팔, 허리 뒤 프레임.
- 패션 분리: 린보다 길고 느슨한 재킷, 공구/소재 느낌은 있으나 정비공 제복으로 보이지 않게 한다.
- 금지: 전투 드론 2기, 장총, 대칭 작업복, 교복형.

## 4. CH103 카나데 노조미 — Resonance Medic

핵심 패션: 부드러운 랩웨어 / 현장 메딕의 곡선 실루엣.

- 큰 색면: 코랄 + 밀크 아이보리 + 아쿠아 민트.
- 헤어: 크림 로즈→코랄 웨이브 + 한쪽 얇은 브레이드.
- 대표 장비: 짧은 공명 배턴 + 2~4개의 큰 패널로 읽히는 응급 베일.
- 실루엣: 얼굴을 열어 둔 부드러운 상체, 넓은 보호 곡선, 5인 중 가장 따뜻한 인상.
- 패션 분리: 검정 비중을 가장 낮게 두고, 곡선·랩·반투명 재질을 활용한다.
- 금지: 간호 모자, 적십자, 현실 의료복 복제, 마법소녀형, Cloth 필수 구조.

## 5. CH104 시온 타테가미 — Orbital Surveyor

핵심 패션: 도시형 드레스 / 측량·기하학 패션.

- 큰 색면: 포슬린 아이보리 + 딥 인디고 + 핫 마젠타.
- 헤어: 딥 인디고 롱 레이어 + 끝 마젠타 빛 + 비대칭 앞머리.
- 대표 장비: 프리즘 부채 + 단일 지도 링.
- 실루엣: 5인 중 가장 곧고 긴 하체, 재킷 드레스의 수직선과 부채의 기하학을 강조.
- 패션 분리: 전술 스트랩보다 정제된 절개와 기하학 패널을 사용한다.
- 금지: 저격총 회귀, 다수 부유 링, 모든 방향에 작은 네온 기호를 붙이는 구조.

## 6. CH105 쿠로가네 아카리 — Anchor Vanguard

핵심 패션: 중량 전위 / 보호 장비를 패션으로 재해석한 실루엣.

- 큰 색면: 딥 네이비/차콜 + 스틸 그레이 + 제한된 청록/앰버 기능색.
- 헤어: 다른 4명보다 단단하고 넓게 읽히는 형태, 얼굴은 가리지 않는다.
- 대표 장비: 양손 건틀릿 + 하나의 큰 앵커 장치. 케이블은 Line/VFX 전제.
- 실루엣: 어깨·전완·부츠에 무게 중심, 허리는 정리해 성인 여성 체형을 잃지 않는다.
- 패션 분리: 장갑/보호 패널의 큰 덩어리로 탱커성을 주되 중갑 기사로 가지 않는다.
- 금지: 대형 방패 회귀, 전신 중갑, 실제 Cable Physics 필수 구조.

## 8. 이번 First-Pass의 승인 범위

이 단계의 결과는 **Roster Direction REVIEW**다. 개별 캐릭터 `APPROVED`가 아니다.

- 5인이 충분히 분리되면 CH101 후보 3안 Gate A를 계속한다.
- CH101을 먼저 사람 선택한 뒤 제작 시트와 2D→3D Proof로 이동한다.
- 나머지 4명은 CH101 Character Proof가 성공한 뒤 각자 3안/세부 제작으로 확장한다.
- 5인 First-Pass에서 겹치는 캐릭터가 있으면 해당 캐릭터만 재탐색한다.
