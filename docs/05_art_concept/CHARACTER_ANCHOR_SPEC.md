# Re:Camp Character Anchor Specification

> Version: 3.0
> 최종 갱신: 2026-08-09
> 상태: New Concept Baseline — Gate A Pending

이 문서는 이미지 생성 도구, 2D 제작, Blender, Unity가 달라도 새 5인 로스터를 같은 캐릭터로 유지하기 위한
도구 비종속 앵커다. `CHARACTER_BIBLE.md`가 캐릭터의 의미·역할·서사를 정의하고, 이 문서는 제작 중 변형 가능한
범위와 금지 회귀를 정의한다.

기존 루나·미유·코코·이리스·노아 및 과거 라인업 이미지는 `HISTORY ONLY`다. 새 후보에 그 얼굴·헤어·의상·장비를
재사용하지 않는다. 사람 승인된 개별 제작 시트가 생기면 해당 시트가 이 문서보다 얼굴·의상·장비 구조에서 우선한다.

## 1. 앵커 강도

| 등급 | 의미 | 변경 조건 |
|---|---|---|
| `LOCKED` | 캐릭터 정체성 또는 제품 방향 | 사용자 결정 또는 Character Bible 개정 필요 |
| `CONTROLLED` | 같은 캐릭터로 읽히는 범위의 제작 조정 | 변경 이유와 비교 이미지 기록 |
| `OPEN` | 산출물별 포즈·표정·세부 배치 | 상위 앵커와 충돌하지 않으면 자유 |
| `FORBIDDEN` | 역할 혼동·성별·비율·세계관 회귀·외부 IP 모방 | 후보에서 제외 |

## 2. 공통 앵커

### `LOCKED`

- 플레이어블은 정확히 아마사와 린, 키사라기 마오, 카나데 노조미, 시온 타테가미, 쿠로가네 아카리의 성인 여성 5명이다.
- 일본 모바일 서브컬처 계열의 성인 애니메이션 얼굴과 깨끗한 셀 색면을 사용한다.
- 2D 대표 전신은 약 6.8~7.4등신이며 기본 목표는 약 7등신이다.
- 인게임 3D는 약 5.2~5.8등신 스타일라이즈드 체형이다.
- 2D와 3D는 같은 캐릭터로 읽히되 동일한 신체 비율과 장식 수를 복사하지 않는다.
- 성인 여성의 얼굴·헤어·허리선·패션·자세·표정·기능성 장비를 함께 설계한다.
- 한 문장 훅, 대표 장비 1개, 보조 특징 2개만으로 쿼터뷰에서 식별 가능해야 한다.
- 자연에 잠식된 폐허, 회수·귀환·캠프 성장이라는 Re:Camp 세계 기능을 시각적으로 연결한다.
- 사용자 레퍼런스의 품질·분위기·마감·패션 밀도만 흡수하고 고유 IP 요소는 복제하지 않는다.
- 승인 전 모든 제작물의 상태는 `REVIEW`다.

### `CONTROLLED`

- 캐릭터별 2D 목표 등신과 3D 목표 등신
- 얼굴형·눈매·헤어 덩어리·대표색
- 대표 장비의 기능적 구조와 쿼터뷰 실루엣
- 어깨·허리·다리의 성인 패션 실루엣
- 이동·기본 공격·대표 스킬·승리 모션의 첫인상
- 조명·VFX가 캐릭터 대표색을 덮지 않는 범위의 재질 반사

### `FORBIDDEN`

- 기존 5인 캐릭터의 얼굴·헤어·의상·무기·포즈를 재사용하는 변형
- 외부 작품의 고유 캐릭터·로고·무기·의상 패턴·UI를 직접 복제하는 결과
- 2D 6.5등신 미만의 유아형 대표 일러스트
- 3D 2~3등신 치비 또는 6등신을 크게 넘는 가늘고 긴 체형
- 남성 플레이어블 또는 성별이 모호한 신체·얼굴
- 쿼터뷰에서 역할을 읽을 수 없는 미세 장식 중심의 디자인
- 무기와 기능이 바뀌어 다른 캐릭터가 되는 팔레트 스왑

## 3. 캐릭터별 앵커

### CH101 아마사와 린 `Amasawa Rin`

- `LOCKED` 훅: 폐허의 길을 빛나는 신호 리본으로 그리는 신호 주자
- `LOCKED` 역할: 기동 근접·정찰
- `LOCKED` 대표 장비: 손목 접이식 단일 와이어 세이버 + 어깨 신호 리본
- `LOCKED` 헤어: 펄 블랙 단발, 청록 언더라이트, 한쪽 긴 묶음
- `LOCKED` 대표색: 펄 화이트·딥 차콜·청록·버밀리온 소량
- `CONTROLLED` 2D/3D: 6.9~7.1H / 5.3~5.4H
- `OPEN`: 리본이 흐르는 방향, 표정의 장난기, 재킷 절개와 경로 비콘의 세부 배치
- `FORBIDDEN`: 고양이형 후드·귀, 쌍단검, 일반 닌자·암살자, 총기 중심 실루엣

## 4. 산출물별 적용

| 산출물 | 반드시 고정 | 검토 포인트 |
|---|---|---|
| 2D 전신 후보 | 등신, 얼굴 인상, 헤어 덩어리, 패션 실루엣, 대표 장비 | 한 문장 훅과 성인 여성 매력 |
| Front·Side·Back | 의상 절개, 장비 결합, 후면 구조, 길이 | 시점 간 구조 일치와 제작 가능성 |
| 표정 시트 | 얼굴 비율, 헤어, 대표 포인트색 | 기본·임무·반전 감정이 모두 가능한가 |
| 흑백 실루엣 | 대표 장비와 자세 | 128px 및 쿼터뷰 식별성 |
| 3D Blockout | 목표 등신, 머리·손·발·장비 강조 | 공용 Humanoid 호환과 관절 가동 |
| Unity Prefab | 재질 슬롯, 장비 소켓, Animator, VFX 소켓 | 성능 예산과 Presentation 계약 |
| UI 초상화 | 얼굴·헤어·포인트색 | 작은 크기 식별성과 감정 전달 |

## 5. 승인 상태

- `REVIEW`: 새 후보·비교 보드·생성 이미지. 최종 제작에 사용하지 않는다.
- `CONDITIONAL`: 사용자 피드백 반영 중이며 제한된 다음 단계만 허용한다.
- `APPROVED`: 사용자가 명시적으로 승인한 개별 제작 시트. 해당 시트가 캐릭터별 최우선 앵커가 된다.
- `REJECTED`: 역할 혼동·원작성 부족·게임 기능 불일치·제작 불가능 중 하나 이상으로 폐기한다.
- `SUPERSEDED`: 새 승인안으로 교체된 이전 후보. 역사 비교만 허용한다.
- `ARCHIVE`: 과거 방향 또는 기록 보존용 자산.

현재 5명 모두 `REVIEW`, 사람 Gate A 승인 `0/5`다.
