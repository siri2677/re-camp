# Re:Camp Current Generation Character Anchor Specification

> Version: 3.1
> 최종 갱신: 2026-08-10
> 상태: Active Production Anchor / Gate A Pending

전역 로스터·비율·플랫폼·공통 비주얼·1인 제작 예산은 `docs/00_project/CURRENT_PROJECT_BASELINE.md`가 소유한다. 캐릭터의 성격·전투·캠프 역할과 외형 설명은 `CHARACTER_BIBLE.md`가 소유한다. 이 문서는 **후보 생성·2D 제작·Blender·Unity 사이에서 각 캐릭터의 정체성을 유지하기 위한 LOCKED/CONTROLLED/OPEN/FORBIDDEN 항목**만 정의한다.

사람 승인된 개별 제작 시트가 생기면 얼굴·의상·장비의 정확한 형태는 해당 Approved 시트가 이 텍스트보다 우선한다.

## 1. 앵커 강도

| 등급 | 의미 | 변경 조건 |
|---|---|---|
| `LOCKED` | 캐릭터가 다른 인물로 변하지 않게 지켜야 하는 핵심 | 사용자 결정 또는 Character Bible 개정 |
| `CONTROLLED` | 같은 캐릭터로 읽히는 범위의 제작 조정 | 비교 이미지와 변경 이유 기록 |
| `OPEN` | 후보별 탐색 가능 | 상위 앵커와 충돌하지 않으면 자유 |
| `FORBIDDEN` | Legacy 회귀·역할 혼동·외부 IP 모방·제작비 폭증 | 후보 제외 |

공통 성인성, 전역 2D/3D 허용 범위, 비복제, Production Budget은 Baseline을 그대로 적용하며 이 문서에 복제하지 않는다.

## 2. CH101 아마사와 린

### LOCKED

- 한 문장 훅: 폐허의 길을 신호 리본으로 그리는 신호 주자.
- 대표 장비: 손목 접이식 단일 와이어 세이버 + 하나의 큰 신호 리본.
- 헤어: 펄 블랙 계열 단발, 청록 언더라이트, 한쪽 긴 묶음 포인트.
- 실루엣: 낮은 전진 자세, 비대칭 상체, 얼굴과 리본이 동시에 읽힘.
- 대표색: 펄 화이트·딥 차콜·청록, 버밀리온 소량.

### CONTROLLED

- 재킷 절개와 길이.
- 리본의 폭·경로·Emission 강도.
- 세이버 Handle과 발광 Blade의 세부 구조.
- 헤어 길이와 묶음 위치.

### OPEN

- 후보별 표정·손짓·캠프 생활 포즈.
- 작은 버클·파우치·경로 비콘의 위치.

### FORBIDDEN

- 고양이 귀·센서 후드·쌍단검 등 Legacy 루나 회귀.
- 일반 닌자·암살자·총기 중심 실루엣.
- 리본을 다수 물리 케이블로 바꿔 Production Budget을 초과하는 구조.

## 3. CH102 키사라기 마오

### LOCKED

- 한 문장 훅: 버려진 재료로 접히는 활을 만드는 폐허 설계자.
- 대표 장비: 접이식 자기 활 + 허리/등의 구조 프레임.
- 헤어: 잿빛 라벤더 롱 보브 + 산성 레몬 언더라이트 + 비대칭 앞머리.
- 실루엣: 한쪽 큰 소매와 접힌/펼친 활의 비대칭.
- 대표색: 울트라바이올렛·그래파이트·산성 레몬.

### CONTROLLED

- 구조 프레임 수와 전개 각도.
- 활의 접힘 단계와 크기.
- 워크 재킷의 소재·절개.
- 공중 설계도 VFX 모양.

### OPEN

- 공구·재료 샘플·작업 포즈.
- 후보별 하의 패널 형태와 보조 액세서리.

### FORBIDDEN

- 전투 드론 2기 등 Legacy 미유 회귀.
- 장총·저격총·대칭 작업복·교복 인상.
- 구조 링마다 독립 Rig/Physics를 요구하는 과도한 기계 구조.

## 4. CH103 카나데 노조미

### LOCKED

- 한 문장 훅: 죽어가는 신호를 공명으로 붙잡는 현장 의무관.
- 대표 장비: 짧은 공명 배턴 + 펼쳐지는 큰 곡선의 응급 베일.
- 헤어: 크림 로즈→코랄 웨이브 + 한쪽 얇은 브레이드.
- 실루엣: 얼굴을 열어 둔 랩 레이어와 넓은 보호 곡선.
- 대표색: 코랄·밀크 아이보리·아쿠아 민트.

### CONTROLLED

- 베일 패널 수와 길이.
- 랩 재킷의 묶임 방향.
- 앰플·의료 소품의 크기와 수.
- 공명 VFX의 꽃잎/파형 비율.

### OPEN

- 캠프 치료 포즈·현장 지휘 포즈.
- 작은 구조 픽토그램·스트랩 위치.

### FORBIDDEN

- 간호 모자·적십자·직접적인 현실 의료복 복제.
- 불투명 대형 방패·유아형 마법소녀.
- 실제 Cloth Simulation이 필수가 되는 지나치게 많은 베일 조각.

## 5. CH104 시온 타테가미

### LOCKED

- 한 문장 훅: 빛의 지도를 접어 폐허의 약점을 읽는 궤도 측량사.
- 대표 장비: 접으면 나침반, 펼치면 측량 장비로 읽히는 프리즘 부채 + 단일 지도 링.
- 헤어: 딥 인디고 롱 레이어 + 끝부분 마젠타 빛 + 비대칭 앞머리.
- 실루엣: 곧은 자세·긴 하체·부채의 기하학.
- 대표색: 포슬린 아이보리·딥 인디고·핫 마젠타.

### CONTROLLED

- 부채 패널 수와 전개 크기.
- 지도 링의 지름·위치·Emission.
- 재킷 드레스와 스커트 패널 길이.
- 프리즘 VFX의 선 수와 각도.

### OPEN

- 지도 투영 포즈·캠프 기록 포즈.
- 작은 측량 장식·지도 리본 위치.

### FORBIDDEN

- 현실 총기·장총·저격수·검정 암살자 등 Legacy 이리스 회귀.
- 긴 에너지 랜스·단순 마법 지팡이.
- 여러 개의 독립 Orbit Ring을 항상 유지하는 과도한 구조.

## 6. CH105 쿠로가네 아카리

### LOCKED

- 한 문장 훅: 무너지는 길에 닻을 박아 숨 쉴 공간을 만드는 전위 수호자.
- 대표 장비: 양손 키네틱 건틀릿 + 하나의 앵커 링 + 제한된 앵커 라인.
- 헤어: 블랙→포레스트 그린 짧은 레이어 + 코퍼 핀.
- 실루엣: 안정적인 어깨·하체·허리선, 낮은 방어 자세.
- 대표색: 포레스트 그린·딥 블랙·브론즈 코퍼.

### CONTROLLED

- 건틀릿 크기와 충격판 구조.
- 앵커 링 크기·위치.
- 볼레로와 하이웨이스트 팬츠의 절개.
- 앵커 Line/VFX의 두께와 범위.

### OPEN

- 정비 포즈·캠프 방어 포즈.
- 작은 버클·공구·시설 보강 마킹.

### FORBIDDEN

- 대형 물리 방패·전신 중장갑 등 Legacy 노아 회귀.
- 얼굴을 가리는 헬멧·남성 탱커형 실루엣.
- 실제 Cable Physics와 다수 충돌 체인을 필수로 하는 구조.

## 7. 후보 회귀 검사

새 후보·수정본마다 다음을 확인한다.

1. Baseline의 Active ID·한 문장 훅과 일치하는가.
2. 해당 캐릭터 LOCKED 항목이 모두 남아 있는가.
3. CONTROLLED 변경은 왜 바뀌었는지 비교 기록이 있는가.
4. 다른 Current 캐릭터의 대표 장비·헤어·팔레트로 수렴하지 않는가.
5. Legacy 캐릭터의 핵심 모티프가 다시 들어오지 않았는가.
6. 외부 IP의 고유 요소를 직접 복제하지 않았는가.
7. 쿼터뷰와 128px에서 핵심 실루엣이 읽히는가.
8. Baseline Production Budget으로 3D 구현 가능한가.

Gate A 전 자산은 `REVIEW`, 승인된 개별 제작 시트만 `APPROVED`로 승격한다.
