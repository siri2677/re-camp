# Re:Camp Art Direction

> Version: 3.0
> 최종 갱신: 2026-08-09
> 상태: New Concept Baseline — Gate A Pending

## 1. 최종 비주얼 정의

Re:Camp의 비주얼은 **매력적인 성인 여성 서브컬처 캐릭터 + 자연에 잠식된 부드러운 포스트 아포칼립스 + 희망적인 캠프 생활**의 조합이다.
배경은 위협적이지만 캐릭터와 캠프는 따뜻하다. 캐릭터의 외형·성격·관계·성장과 모바일 플레이 가독성을 배경의 사실성보다 우선한다.

```text
2D 약 7등신 성인 서브컬처 캐릭터 일러스트
+ 3D 5~6등신 스타일라이즈드 인게임 캐릭터
+ 스타일라이즈드 폐허와 캠프
+ 툰 셰이딩
+ 고정 Orthographic 쿼터뷰 전투
```

## 2. 표현 방식

| 구분 | 최종 방향 |
|---|---|
| 캐릭터 Key Art | 약 6.8~7.4등신, 일본 모바일 서브컬처 계열 성인 애니메이션 일러스트 |
| 제작 시트 | 2D 약 7등신 Front·Side·Back, 얼굴·의상·장비 상세 |
| 인게임 캐릭터 | 3D 5~6등신 스타일라이즈드 모델, 캐릭터별 약 5.2~5.8등신 |
| UI 초상화 | 2D 얼굴·상반신 중심, 헤어·눈매·대표색 강조 |
| 카메라 | 고정 Orthographic 쿼터뷰 |
| 렌더링 | 툰 셰이딩, 큰 명암면, 제한된 하이라이트 |
| 배경 | 자연에 잠식된 스타일라이즈드 폐허와 따뜻한 캠프 |
| UI | 둥근 패널, 가벼운 글래스, Android Landscape 가독성 |

## 3. 캐릭터 디자인 원칙

### 3.1 한 문장으로 기억되는 디자인

각 캐릭터는 이름과 색을 가려도 대표 장비와 자세만으로 한 문장 설명이 가능해야 한다.

- 아마사와 린: 폐허의 길을 빛나는 신호 리본으로 그리는 신호 주자
- 키사라기 마오: 버려진 재료로 접히는 활을 만드는 폐허 설계자
- 카나데 노조미: 죽어가는 신호를 공명으로 붙잡는 현장 의무관
- 시온 타테가미: 빛의 지도를 접어 폐허의 약점을 읽는 궤도 측량사
- 쿠로가네 아카리: 무너지는 길에 닻을 박아 숨 쉴 공간을 만드는 전위 수호자

### 3.2 패션과 기능의 결합

- 의상은 몸의 움직임·보호·수납·신호 기능 중 하나 이상을 시각적으로 설명한다.
- 얼굴과 헤어는 큰 덩어리로 정리해 작은 초상화와 쿼터뷰에서 식별한다.
- 노출은 기능성 레이어·허리선·자세와 함께 설계하며 노출 자체를 캐릭터 훅으로 사용하지 않는다.
- 대표 장비는 신체 실루엣과 분리되어도 누구의 장비인지 읽혀야 한다.
- 각 캐릭터는 `대표 특징 1개 + 보조 특징 2개`로 요약한다.

### 3.3 감정 대비

- 린: 장난스러운 자신감 ↔ 동료를 두고 갈까 두려운 집중
- 마오: 졸린 무관심 ↔ 구조를 설명할 때의 과열된 열정
- 노조미: 따뜻한 미소 ↔ 사고 순간의 짧고 강한 지휘
- 시온: 우아한 완벽주의 ↔ 생활 공간에서의 방향 감각 부족
- 아카리: 무뚝뚝한 통제 ↔ 말보다 행동으로 드러나는 배려

### 3.4 성인성·원작성

- 성인성은 긴 팔다리, 어깨·허리·골반 비율, 패션, 자세, 표정에서 확보한다.
- 2D 대표 이미지는 6.5등신 미만의 유아형 체형을 사용하지 않는다.
- 3D는 치비가 아니며 5~6등신의 플레이 가능한 실루엣을 사용한다.
- 외부 레퍼런스는 품질 매트릭스로만 사용한다. 고유 얼굴·의상·무기·포즈·로고·UI를 복제하지 않는다.
- 사람이 승인하지 않은 생성물은 `REVIEW`이며 `APPROVED` 또는 `Direction Approved`로 표시하지 않는다.

## 5. 실루엣과 재질 규칙

### CH101 아마사와 린

- 펄 블랙 단발, 청록 언더라이트, 비대칭 펄 화이트 재킷
- 어깨에서 흐르는 하나의 큰 신호 리본과 손목 접이식 세이버
- 빠른 이동을 읽히게 하는 낮은 전진 자세와 긴 다리 라인
- 매트 나일론·반투명 신호 필름·얇은 브러시드 메탈

### CH102 키사라기 마오

- 잿빛 라벤더 롱 보브, 비대칭 대형 소매, 허리 뒤 세 개의 구조 링
- 접히고 펼쳐지는 자기 활 프레임을 등 실루엣의 중심에 둔다.
- 작은 체형이지만 성인 패션의 허리·다리 비율을 유지한다.
- 고무 코팅 원단·긁힌 알루미늄·투명 폴리카보네이트

### CH103 카나데 노조미

- 크림 로즈 웨이브, 코랄 랩 재킷, 응급 베일의 큰 곡선 패널
- 공명 배턴은 손 동작을 가리지 않는 짧고 선명한 실루엣으로 만든다.
- 부드러운 곡선과 현장 활동성을 함께 보여 준다.
- 방수 원단·반투명 폴리머·새틴 테이프·소형 버클

### CH104 시온 타테가미

- 딥 인디고 롱 레이어, 포슬린 재킷 드레스, 핫 마젠타 끝빛
- 부채를 접었을 때 나침반, 펼쳤을 때 프리즘 측량 장비로 읽힌다.
- 긴 천은 큰 면으로 정리하고 지도 링은 한 개의 명확한 궤도로 제한한다.
- 코팅 원단·반사 세라믹·투명 프리즘·얇은 금속 링

### CH105 쿠로가네 아카리

- 블랙-포레스트 그린 짧은 헤어, 크롭 아머드 볼레로, 코퍼 버클
- 양손 건틀릿과 등 뒤 앵커 링으로 힘을 표현하고 대형 방패는 사용하지 않는다.
- 안정적인 하체와 똑바른 허리선으로 전위 수호자의 존재감을 만든다.
- 보호 섬유·검은 고무·브러시드 스틸·구리 전도체

## 6. 색·광원·VFX

- 캐릭터별 Primary 1개, Secondary 1~2개, Accent 1개, Emission 1개를 넘기지 않는다.
- 배경의 녹색·회색 자연 침식 톤과 캐릭터의 대표색을 명확히 분리한다.
- 린은 청록 경로선, 마오는 보라-레몬 자기선, 노조미는 아쿠아 공명 파동,
  시온은 백색-마젠타 프리즘선, 아카리는 코퍼-황금 앵커 격자를 사용한다.
- VFX는 얼굴·대표 장비·적의 약점보다 밝아지지 않는다.
- 작은 화면에서도 캐릭터를 보지 않고 이펙트만 보아 역할을 구분할 수 있어야 한다.

## 7. 캠프·배경과의 대비

- 린의 경로 리본은 폐허의 길과 캠프의 귀환 표식을 시각적으로 연결한다.
- 마오의 구조 프레임은 버려진 건축물과 캠프 작업대를 연결한다.
- 노조미의 공명 안테나는 생존자 신호와 캠프의 따뜻한 조명을 연결한다.
- 시온의 지도 링은 먼지·빛·폐허의 기하학을 정리한다.
- 아카리의 앵커 격자는 캠프 방어선과 붕괴 지형을 연결한다.

## 8. 금지 목록

- 기존 루나·미유·코코·이리스·노아의 얼굴·헤어·의상·무기·포즈를 신규 디자인의 기준으로 삼는 것
- 서로 다른 캐릭터를 색만 바꾼 동일한 전술복·동일 체형으로 만드는 것
- 외부 IP의 고유 디자인이나 로고를 직접 복제하는 것
- 새 캐릭터를 기존 캐릭터의 이름만 바꾼 리스킨으로 기록하는 것
- 2D 6.5등신 미만, 3D 2~3등신, 과도하게 긴 7등신 초과 체형
- 쿼터뷰에서 읽히지 않는 미세 장식과 얼굴을 가리는 장비
- AI 결과를 구조 검수 없이 최종 원화·3D 설계도로 사용하는 것

## 9. 레퍼런스 상태와 우선순위

- 현재 5인 후보는 전부 `REVIEW`, 사람 Gate A 승인 `0/5`다.
- 기존 `ReCamp_CharacterLineup_REVIEW_v003.png`와 이전 캐릭터별 REVIEW 자산은 `HISTORY ONLY`다.
- 새 후보의 제작 시트가 사람 승인을 받으면 해당 시트가 라인업·무드보드보다 우선한다.
- 생성 이미지는 자동으로 승인되지 않는다.
- `ART_REVIEW_CHECKLIST.md`의 원작성·성인성·기능·쿼터뷰 식별성·제작 가능성 항목을 모두 통과해야 다음 단계로 간다.
