# Re:Camp Current Generation Art Direction

> Version: 3.1
> 최종 갱신: 2026-08-10
> 상태: Active Visual Language Contract

전역 로스터·플랫폼·2D/3D 비율·세대 구분은 `docs/00_project/CURRENT_PROJECT_BASELINE.md`가 소유한다. 캐릭터별 얼굴·헤어·의상·장비·팔레트는 `CHARACTER_BIBLE.md`와 `CHARACTER_ANCHOR_SPEC.md`가 소유한다. 이 문서는 **모든 Current Generation 자산에 공통으로 적용되는 화풍·색·재질·환경·UI·VFX 표현 규칙**만 관리한다.

## 1. 비주얼 기둥

```text
매력적인 성인 여성 서브컬처 캐릭터
+ 자연에 잠식된 부드러운 포스트 아포칼립스
+ 위험 구역과 대비되는 따뜻한 캠프 생활
+ 모바일 쿼터뷰에서 즉시 읽히는 전투 정보
```

캐릭터 애착과 플레이 가독성을 환경의 사실성보다 우선한다.

## 2. 캐릭터 공통 표현

- 얼굴은 큰 애니메이션 형태, 깨끗한 셀 색면, 제한된 소프트 그라데이션을 사용한다.
- 서양권 반실사 피부·무거운 페인터리 렌더링을 기본 화풍으로 사용하지 않는다.
- 헤어는 작은 가닥보다 큰 덩어리와 읽기 쉬운 외곽 형태를 우선한다.
- 패션은 단순 직업 코스튬보다 도시형 의복과 생존·탐험 기능 장비를 결합한다.
- 대표 특징 1개와 보조 특징 2개가 작은 화면에서 읽혀야 한다.
- 얼굴·상체·대표 장비 주변에 시선 초점을 만들고 다리 아래쪽의 미세 장식 밀도는 낮춘다.
- 모든 캐릭터를 같은 검정 전술복·같은 얼굴·같은 네온선으로 수렴시키지 않는다.

## 3. 2D→3D 표현 원칙

정확한 전역·캐릭터별 비율은 Canonical Baseline과 Approved 제작 시트를 따른다.

| 항목 | 2D Key Art | 3D In-game |
|---|---|---|
| 목적 | 얼굴·패션·표정·재질·매력 | 조작·전투 가독성·애니메이션·성능 |
| 얼굴 | 미세 눈매·입·표정과 화장 | 눈매·헤어라인·대표 표정 중심 |
| 의상 | 레이어·절개·재질 설명 | 큰 색면·실루엣 보존, 미세 장식 축소 |
| 장비 | 구조와 사용법 상세 | 종류·방향·활성 상태 즉시 식별 |
| 동적 요소 | 흐름과 분위기 표현 가능 | 최소 Bone/Transform/Shader/VFX로 단순화 |

제작 시트에는 `2D to 3D Simplification`을 작성하고 확대·삭제·결합·물리 제거 항목을 명시한다.

## 4. 실루엣과 작은 화면

- 정면·측면·후면·전투 3/4에서 같은 캐릭터로 보여야 한다.
- 128px 얼굴, 흑백 실루엣, 저채도, 대표 장비 on/off 상태를 검토한다.
- 캐릭터가 장비에 완전히 의존하지 않도록 헤어·상체·자세만으로도 차이를 남긴다.
- 대표 장비가 얼굴·손·적·피격 위치를 가리지 않게 한다.
- 긴 천·링·리본·케이블은 큰 형태로 단순화하고 카메라 가림과 관통을 먼저 검토한다.

## 5. 환경

### 위험 구역

- 자연이 침식한 폐허·거리·연구 시설·지하 공간·기계 잔해를 사용한다.
- 잔혹함보다 시간이 지나며 자연과 인공물이 섞인 아름다운 폐허를 지향한다.
- 중앙 교전 공간은 읽기 쉽게 비우고 큰 폐허·식생·바리케이드는 가장자리에 배치한다.
- 이동 가능 영역, 위험, 자원, 상호작용은 명도·형태·VFX로 구분한다.
- 배경은 캐릭터보다 낮은 채도와 디테일 밀도를 유지한다.

### 캠프

- 따뜻한 조명과 정돈된 수리 흔적을 사용한다.
- 발전·수리·저장·통신처럼 플레이 기능을 생활 공간으로 표현한다.
- 성장할수록 조명·설비·개인 소품·생활감이 증가한다.
- 캐릭터별 개인 공간은 Character Bible의 성격과 캠프 역할을 시각적으로 보조한다.

## 6. 컬러와 광원

```text
공통 기반: 차콜 / 웜 그레이 / 크림 / 자연 녹색
안전·생활: 따뜻한 앰버와 부드러운 실내광
기술·전투: 캐릭터별 제한된 Accent와 Emission
위험: 적·경고가 캐릭터 고유색과 혼동되지 않는 별도 신호색
```

- 캐릭터별 세부 팔레트는 Character Bible이 소유한다.
- 캐릭터와 공격 피드백은 배경보다 높은 대비를 가진다.
- 기능 없는 대면적 네온은 사용하지 않는다.
- 발광은 탐지·치료·약점·방어·경로·장비 활성 같은 실제 기능을 설명할 때 사용한다.

## 7. 재질과 셰이딩

- 얼굴: 부드러운 명암, 그림자 최소화, 눈·입·표정 우선.
- 피부: 과도한 실사 노멀·모공·강한 광택을 피한다.
- 천: 큰 색면과 제한된 하이라이트.
- 기능 장비: 무광 플라스틱·세라믹·브러시드 금속·반투명 폴리머를 목적에 맞게 사용.
- 환경: 캐릭터보다 거친 재질을 쓰되 작은 노이즈를 과도하게 늘리지 않는다.
- 공용 Toon Shader와 Material 구조를 우선해 1인 제작·모바일 유지비를 낮춘다.

## 8. UI

- 둥근 버튼과 패널, 얇은 외곽선, 가벼운 글래스 표현.
- 필수 정보와 조작은 Safe Area 안에 배치한다.
- 전투 HUD는 체력·타이머·임무·스킬·귀환 판단에 집중한다.
- 장식 패널보다 플레이 영역을 우선한다.
- 초상화는 얼굴·헤어·눈매·대표색으로 즉시 구분한다.
- 버튼 상태는 Normal·Pressed·Cooldown·Disabled·Interrupted가 명확해야 한다.

모바일 입력·Lifecycle의 기능 계약은 `docs/04_ui_ux/MOBILE_INPUT_AND_LIFECYCLE.md`를 따른다.

## 9. VFX

- 공격 종류·방향·범위·상태를 먼저 전달한다.
- 캐릭터별 VFX는 Character Bible의 장비 기능과 팔레트에서 파생한다.
- 큰 불투명 효과로 캐릭터·적·바닥 위험 표시를 가리지 않는다.
- 치료·보호·약점·경로·자원 흡입은 형태 언어가 서로 달라야 한다.
- 모바일 Overdraw와 동시 파티클 수를 제한한다.
- 복잡한 Cloth/Cable/Geometry Animation 대신 Shader, Trail, Line, Decal, 간단한 Transform을 우선한다.

## 10. 외부 레퍼런스 사용

외부 작품은 다음 품질 축만 분석한다.

- 얼굴 마감과 표정 전달력.
- 패션 레이어의 밀도와 소재 대비.
- 실루엣과 대표 장비의 가독성.
- Key Art 광원과 색 대비.
- UI와 캐릭터의 시선 우선순위.

고유 캐릭터·얼굴·헤어·의상·무기·포즈·로고·UI 구조를 직접 복제하지 않는다. 생성 이미지도 동일한 기준을 적용하며 사람 Gate 전에는 REVIEW다.

## 11. 금지 스타일

- 과도한 실사·무거운 AAA 밀리터리·잔혹한 고어.
- 얼굴을 가리는 헬멧·장비.
- 쿼터뷰에서 읽히지 않는 미세 장식 중심 디자인.
- 동일 얼굴·체형·전술복의 팔레트 스왑.
- 기능 없이 장식만 늘어난 부유 링·케이블·네온선.
- AI 결과를 구조 검수 없이 최종 원화나 3D 설계도로 사용.
- Production Budget을 무시하는 캐릭터별 독립 Shader/Rig/Physics 시스템.

## 12. 승인 우선순위

```text
개별 사람 APPROVED 제작 시트
→ Character Bible / Anchor Spec
→ 이 Art Direction
→ 승인된 환경·UI Style Guide
→ REVIEW/WIP 자산
→ Legacy·REJECTED·INVALID 자산
```

이 문서에서 전역 로스터·플랫폼·정확한 비율·현재 Gate를 다시 정의하지 않는다.
