# Re:Camp Game Concept

> Current Generation의 플랫폼·활성 로스터·전역 비율·출시 범위는 `docs/00_project/CURRENT_PROJECT_BASELINE.md`를 따른다.

## 한 줄 소개

자연에 잠식된 멸망 이후의 위험 구역을 짧게 탐험하고 자원을 회수해, 따뜻한 생존자 캠프를 성장시키는 싱글플레이 로그라이트 RPG.

## 기획 의도

Re:Camp는 대규모 오픈월드나 고사양 사실적 그래픽보다 **짧은 세션, 위험/보상 판단, 반복 성장, 캐릭터 애착, 귀환 성취감**에 집중한다.

플레이어는 위험 구역에 들어가 이동·전투·탐색으로 자원을 모은다. 탐험이 길어질수록 더 많은 보상을 기대할 수 있지만 손실 위험도 높아지고, 플레이어는 더 진행할지 안전하게 귀환할지 결정한다. 성공적으로 회수한 자원은 캠프 성장에 사용되며 다음 탐험의 생존력과 선택지를 넓힌다.

## 핵심 재미

1. 제한된 시간 안에서 위험 구역을 탐험하는 긴장감.
2. 더 탐험할지 귀환할지 스스로 결정하는 리스크/보상 판단.
3. 자원을 무사히 가져왔을 때의 추출·정산 성취감.
4. 캠프가 누적 성장하며 다음 탐험이 달라지는 장기 목표.
5. 서로 다른 플레이 스타일과 성격을 가진 캐릭터에 대한 애착.

## 플레이어 경험 목표

| 경험 | 목표 |
|---|---|
| 긴장감 | 탐험이 길어질수록 위험이 커진다. |
| 선택 | 귀환 시점과 전투·탐색 우선순위를 결정한다. |
| 숙련 | 같은 캐릭터도 이동·스킬·귀환 판단의 숙련도가 쌓인다. |
| 성장 | 회수 자원이 캠프와 다음 Run에 의미 있는 변화를 만든다. |
| 애착 | 얼굴·패션·성격·역할·대표 장비가 플레이 경험과 연결된다. |

## 캐릭터 설계 원칙

캐릭터는 단순한 외형 수집 대상이 아니라 **전투 방식 + 탐험 판단 + 캠프 세계관 기능**을 하나로 묶는 플레이 스타일이다.

- 전투 역할만 다르고 탐험에서는 동일한 캐릭터가 되지 않게 한다.
- 캐릭터 훅이 대표 장비·자세·VFX·Idle에서 읽혀야 한다.
- 신규 디자인을 이유로 검증된 Gameplay 시스템을 무조건 폐기하지 않는다.
- 캠프 역할은 초기에는 별도 대형 시스템보다 기존 자원·시설 성장과 연결되는 작은 효과로 구현한다.
- 세부 캐릭터 계약은 `docs/05_art_concept/CHARACTER_BIBLE.md`를 따른다.

## 세계 톤

위험 구역은 자연에 잠식된 폐허로, 캠프는 인간의 생활이 되살아나는 따뜻한 공간으로 대비한다.

```text
위험한 폐허
↕
탐험하는 캐릭터
↕
돌아와 쉴 수 있는 캠프
```

재난의 잔혹함보다 **위험한 세계에서도 다시 살아가는 사람들**의 분위기를 우선한다.

## 차별화 포인트

- 직접 이동과 자동 공격을 결합한 쿼터뷰 전투.
- 탐험 후 반드시 귀환을 고민하게 만드는 추출형 리스크/보상 구조.
- 전투 결과가 캠프의 누적 성장으로 연결되는 짧은 반복 루프.
- 전투·탐험·캠프 기능이 외형과 장비에 함께 반영된 캐릭터 설계.
- 자연 침식 폐허와 따뜻한 캠프의 명확한 감정 대비.

## 구현 경계

Current Generation의 디자인 로스터와 현재 Unity Gray Box 로스터는 동일한 것이 아니다. 사람 Gate와 Runtime handoff 전에는 문서 변경만으로 CharacterId·저장·HUD·Prefab·능력을 자동 치환하지 않는다.

정확한 세대 구분과 현재 로스터, 전역 비율, 구현 재사용 원칙은 Canonical Baseline을 따른다.
