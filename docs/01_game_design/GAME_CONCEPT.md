# Re:Camp Game Concept

## 게임명

Re:Camp

## 장르

- Android-first 가로형 모바일 로그라이트 RPG
- 생존 탐험
- 거점 성장
- 성인 여성 캐릭터 수집·성장

## 한 줄 소개

자연에 잠식된 멸망 이후의 위험 구역을 3~5분 동안 탐험하고 자원을 회수해, 따뜻한 생존자 캠프를 성장시키는 싱글플레이 로그라이트 RPG.

## 기획 의도

Re:Camp는 대규모 오픈월드나 고사양 그래픽보다 **짧은 세션, 반복 성장, 캐릭터 애착, 귀환 성취감**에 집중한다.

플레이어는 위험 구역에 들어가 이동·전투·탐색으로 자원을 모으고, 더 탐험할지 안전하게 귀환할지 판단한다. 추출에 성공한 자원은 캠프 시설 강화에 사용되며 다음 탐험의 선택지를 넓힌다.

현재 Unity Runtime은 기존 레거시 Gray Box 자산으로 기능을 검증한다. 제품 디자인 로스터는 CH101~CH105 신규 캐릭터이며, 사람 Gate A/B 승인과 별도 Runtime handoff 전에는 레거시 자산을 문서만으로 교체하지 않는다.

## 핵심 재미

```text
1. 짧은 시간 안에 위험 구역을 탐험하는 긴장감
2. 자원을 들고 무사히 귀환했을 때의 성취감
3. 캠프가 점점 성장하는 누적 성장감
4. 성인 여성 캐릭터의 얼굴·패션·역할·훅에 대한 애착
5. 매 판 전투와 귀환 판단을 조절하는 반복성
```

## 플레이어 경험 목표

| 경험 | 설명 |
|---|---|
| 긴장감 | 탐험 시간이 지날수록 위험과 손실 가능성이 증가한다. |
| 선택 | 귀환할지 더 탐험할지 결정한다. |
| 성장 | 추출 자원으로 캠프 시설을 강화한다. |
| 애착 | 신규 5인은 명확한 성인 여성성·성격·역할·대표 장비를 갖는다. |
| 반복성 | 3~5분 세션을 반복해도 캠프와 숙련도가 누적된다. |

## 비주얼 톤

```text
성인 여성 5인의 일본 모바일 서브컬처 매력
+ 자연에 잠식된 부드러운 포스트 아포칼립스 폐허
+ 따뜻한 생존자 캠프
+ 쿼터뷰에서 읽히는 장비·실루엣
+ Android Landscape 친화적 UI
```

2D 대표 일러스트는 약 6.8~7.4등신(기본 약 7등신), 인게임 3D는 캐릭터별 5~6등신 스타일라이즈드 비율을 사용한다. 전투 콘셉트 이미지는 카메라·환경·색 대비 앵커이며 개별 캐릭터 외형과 무기를 자동 복제하는 기준이 아니다.

## 제품 로스터와 현재 구현 로스터

| 범위 | 로스터 | 상태 |
|---|---|---|
| 제품 디자인 | CH101 아마사와 린, CH102 키사라기 마오, CH103 카나데 노조미, CH104 시온 타테가미, CH105 쿠로가네 아카리 | 신규 아트 Gate A 전 `REVIEW`, 승인 0/5 |
| 현재 Unity 기능 검증 | 기존 레거시 Gray Box 5인 | Runtime 회귀용, 최종 아트 아님 |

신규 로스터의 CharacterId·능력·HUD·Prefab·저장 해금 연결은 별도 handoff와 검증 작업으로 수행한다.

## 타깃 유저

- 성인 여성 캐릭터의 매력·수집·성장과 남성향 서브컬처 감성을 선호하는 유저
- 짧은 시간에 성장감을 느끼고 싶은 모바일 RPG 유저
- 로그라이트·생존·탐험 구조를 선호하는 유저
- 복잡한 MMORPG보다 가볍고 반복 가능한 RPG를 원하는 유저

## 차별화 포인트

```text
직접 조작과 자동 공격이 결합된 쿼터뷰 로그라이트 전투
탐험 후 귀환하는 리스크/보상 구조
캠프 시설 성장 기반의 장기 목표
성인 여성 5인의 패션·성격·역할·장비 훅
자연에 잠식된 폐허와 따뜻한 캠프의 대비
```

## 범위 경계

싱글플레이 로컬 저장을 기준으로 하며 실시간 멀티플레이, PvP, 길드, 가챠, 상점 결제, 광고, 오픈월드, 풀 보이스는 초기 출시 범위에 포함하지 않는다. 랜덤 스킬 선택은 후속 시스템 후보이며 현재 구현 사실로 간주하지 않는다.
