# Japanese Subculture Character Style REFERENCE v001 — Scope

The reference establishes the desired Japanese mobile-subculture character sensitivity:

- large jewel-like anime eyes and clean lashes;
- short midface, small nose and mouth, refined jaw;
- attractive, feminine adult character presentation;
- readable anime hair clumps and controlled highlights;
- crisp cel-colored surfaces with restrained soft gradients;
- strong 128px portrait readability.

It does not authorize copying the depicted characters, costumes, user interface, Korean text, scene composition,
weapons, logos, or exact color layouts. Re:Camp's Character Bible and Character Anchor Spec remain authoritative
for identity and equipment. Rights and commercial-use terms for this reference are not verified, so it is not a
release asset.
